STM32H755 · C / C++

ARM Cortex-M7 Real-Time Kernel

A lightweight preemptive RTOS kernel built on static allocation, with priority scheduling across 32 levels, O(1) ready lists, and dynamic-tick timekeeping.

  • Mutexes with transitive priority inheritance, semaphores, queues, notifications, and ISR-safe variants.
  • MPU-based stack-overflow guard and optional C++ RAII wrappers.

STM32F446 · Register-level C

Bare-Metal Driver Library

Peripheral library written without STM32 HAL/LL dependencies, covering RCC, GPIO, EXTI, NVIC, SysTick, PWR, ADC, DMA, and modular timer drivers.

  • Includes PWM, encoder, input capture, synchronisation, and motor-control support.
  • Custom startup code, linker configuration, Makefile build system, and OpenOCD/GDB debug workflow.

STM32L476RG

Low-Power Optical Data Acquisition System

Firmware for a battery-operated optical data logger designed for autonomous operation.

  • State-machine acquisition, differential sampling, ambient-light cancellation, temperature compensation, CRC-32, and SD-card logging.
  • RTC scheduling, Stop 2 power management, watchdog recovery, fault handling, and persistent fault history.

Autonomous Micromouse Navigation

Autonomous maze-navigation and motion-control system using depth-first search with backtracking for exploration and breadth-first search for shortest-path computation.

PID distance and heading control, plus sensor fusion with wheel encoders, gyroscope measurements, and time-of-flight wall following.
